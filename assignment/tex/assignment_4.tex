\section{Conduct a white-hat model extraction attack.}

Use queries to the Assignment 3 model to train and document a surrogate that approximates its predictions. Explain your query strategy, the surrogate model, and how well it reproduces the target model's behavior.\\

\noindent The model extraction attack is worth 3 points.
 
\section{Find adversarial examples for your model.}

Use the Assignment 3 model and your analysis to create at least one valid input that produces a low prediction and at least one that produces a high prediction. Describe the changes made to each input and the resulting predictions.\\

\noindent The adversarial examples are worth 3 points.
